# BattleServer completion checklist

Active objective: implement every BattleServer feature required by the recovered WarFriends 1.4.0 Client, with a working Client integration, then verify the complete result. This checklist does not redefine completion as the existing prototype.

Authority: [Server guide section 6](../../Server_guide.md), active `Clients/ExportedProject` scripts/assets, [communication inventory](client-communication-inventory.json), and executable source/tests. Backend wallet/account implementations belong to the separate Backend effort. Battle-owned allocation/control/result contracts and their integration proof remain in scope. Solo campaign may stay local, but its Photon-free adapter is in scope. No Docker; Windows development and Linux deployment; protobuf; no runtime Photon service.

Status meanings: **partial** = implemented evidence exists but the feature is not complete; **pending** = necessary work is not yet implemented/verified. A green kernel test alone does not close a gameplay feature. No feature below is declared production-complete yet.
